체적저항 측정 시스템 1.2 설치 안내
====================================

1. 설치 전 준비
---------------
- Windows 10/11 64-bit PC를 사용하십시오.
- Keithley 6517B를 GPIB-USB로 사용할 경우 NI-VISA와 NI-488.2 드라이버를 먼저 설치하십시오.
- Technix SR을 RS-232-USB로 사용할 경우 해당 변환기의 Windows 드라이버를 먼저 설치하십시오.
- Microsoft Edge WebView2 Runtime이 없는 PC에서는 WebView2 Runtime을 설치하십시오.
- 자세한 내용은 "설치 전 필수사항.txt"를 확인하십시오.

2. 프로그램 설치
----------------
- "체적저항 측정 시스템 1.2 설치.exe"를 실행합니다.
- Windows SmartScreen 경고가 표시되면 파일 이름과 배포 경로를 확인한 뒤 실행 여부를 선택합니다.
- 기본 설치 위치를 사용하거나 원하는 위치를 지정하여 설치합니다.
- 설치 완료 후 바탕 화면 또는 시작 메뉴의 "체적저항 측정 시스템"을 실행합니다.

3. 최초 실행 및 장비 연결
-------------------------
- 프로그램은 일반 인터넷 브라우저가 아니라 독립된 Windows 창으로 실행됩니다.
- 시스템 설정에서 Technix 통신 포트와 Keithley VISA 리소스를 확인합니다.
- 각 장비의 "연결" 버튼을 눌러 통신을 확인합니다.
- 장비 한 대만 연결된 경우 Manual Start에서 연결된 장비의 기능만 독립적으로 사용할 수 있습니다.
- 고전압 출력 전에는 사용자가 장비의 물리적 인터록, Safe Lock, 접지, 배선 및 시험 영역을 직접 확인해야 합니다.

4. 사용설명서
-------------
- 설치 프로그램에는 최신 PDF/HTML 설명서가 포함됩니다.
- 배포 폴더에서 기존 PDF가 열려 있어 갱신되지 않는 경우에는 파일명에 "최신 개정본"이 붙은 PDF를 사용하십시오.
- HTML: User Manual - 체적저항 측정 시스템 1.2.html

5. 제거
-------
- Windows 설정 > 앱 > 설치된 앱에서 "체적저항 측정 시스템 1.2.0"을 제거합니다.

6. 참고
-------
- 본 배포본은 코드 서명 인증서로 서명되지 않았으므로 다른 PC에서 SmartScreen 경고가 표시될 수 있습니다.
- NI-VISA, NI-488.2 및 USB-RS232 드라이버는 제조사 배포 조건과 하드웨어 종류가 서로 달라 본 ZIP에 포함하지 않았습니다.
- 설치 파일의 무결성은 SHA256SUMS.txt에 기록된 SHA-256 값으로 확인할 수 있습니다.
