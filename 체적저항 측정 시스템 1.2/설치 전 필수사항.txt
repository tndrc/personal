체적저항 측정 시스템 1.2 - 설치 전 필수사항
================================================

1. 지원 환경
- Windows 10/11 64비트
- 관리자 권한이 있는 사용자 계정
- Microsoft Edge WebView2 Runtime

2. 장비 드라이버(별도 설치)
- Keithley 6517B + NI GPIB-USB-HS: NI-VISA 및 NI-488.2 드라이버
- Technix SR 40 P-600-OP + USB-RS232: 사용 중인 USB-RS232 어댑터 드라이버
  (현재 개발 장비는 Prolific 계열 COM 포트로 확인됨)

제조사 드라이버는 라이선스와 장치별 버전 문제 때문에 본 설치 패키지에 포함하지 않습니다.
대상 PC에 드라이버를 먼저 설치한 뒤 Windows 장치 관리자와 NI MAX에서 장비가 인식되는지 확인하십시오.

3. 권장 연결 확인
- Keithley: NI MAX에서 MODEL 6517B가 표시되고 VISA 리소스 이름을 확인
  예: GPIB0::3::INSTR (실제 GPIB 주소에 따라 숫자는 달라질 수 있음)
- Technix: 장치 관리자에서 USB Serial Port의 COM 번호 확인
- Technix 기본 통신값: 9600 baud, 8 data bits, N parity, 1 stop bit, CR terminator

4. 설치 및 실행
- '체적저항 측정 시스템 1.2 설치.exe'를 관리자 권한으로 실행합니다.
- 설치 후 바탕 화면 또는 시작 메뉴의 '체적저항 측정 시스템'을 실행합니다.
- 프로그램은 인터넷 브라우저가 아니라 독립된 Windows 프로그램 창으로 실행됩니다.

5. 안전 주의
- 본 프로그램은 고전압 장비의 물리적 안전장치를 대체하지 않습니다.
- HV ON 또는 전압 인가 전에 작업자가 접지, 인터록, Safe Lock, 배선 및 시험영역 통제를 직접 확인해야 합니다.
- 시험 종료 후 출력전압과 잔류전압이 안전 수준인지 장비 표시 및 적절한 계측 방법으로 확인하십시오.

6. 데이터 위치
- 프로그램 설정과 런타임 정보: %LOCALAPPDATA%\DCVolumeResistivity
- 측정 CSV: 프로그램에서 사용자가 선택한 저장 기준 폴더 아래 날짜/시간 폴더
- 프로그램 제거 시 사용자가 선택한 측정 CSV는 자동 삭제되지 않습니다.
